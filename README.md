# Muestrario de Color

Generador de paletas de colores en una sola página HTML, sin dependencias.

- `Espacio` o **Generar** crea una paleta de 5 colores.
- Click en un color lo copia en HEX, RGB o HSL (elegí el formato arriba).
- El candado fija un color para que no cambie al generar.
- **Copiar paleta** copia los 5 colores separados por coma.
- La barra de abajo guarda los colores copiados.

Para usarlo, abrí `index.html` en el navegador.
